# react-gift-order

## 📌 개요
- [https://kakaotech-mission2-order-step2.pages.dev/](https://kakaotech-mission2-order-step2.pages.dev/)
- 해당 링크에 나와있는대로 카카오톡 선물하기 페이지를 구현합니다. 이전 진행단계에 이어서 로그인하기와 상품 주문 페이지를 구현합니다.

## 🛠️ 기술 스택
- TypeScript, React + Vite

## ✨ 주요 기능
### 로그인 구현
- ID 는 반드시 입력해야하고 이메일 형식이어야 한다. 그렇지 않으면 에러 메세지를 출력한다
- 비밀번호는 8자리 이상이어야한다. 그렇지 않으면 에러 메세지를 출력한다
- 조건을 모두 만족해야만 로그인 버튼이 활성화된다.
### 주문하기 페이지 구현
- 로그인 정보를 어디서든 사용할 수 있도록 한다.
- 새로고침을 하더라도 로그인 정보가 유지한다.
- 로그인 한 유저는 로그인 버튼 클릭 시 마이페이지(/my)로 연결한다.
- 마이페이지는 로그인 한 사람만 접근 가능하다. 로그인 하지 않은 사람이 접속하면 로그인 페이지로 연결한다.
- 로그아웃 시 로그인(/login) 페이지로 연결한다.
### 단체주문 페이지 구현
- 받는 사람 기능 고도화
- 받는 사람을 최대 10명까지 등록 가능하다.
- 10명의 정보가 정확하게 입력되지 않으면 정보가 반영되지 않는다.
- 받는 사람의 전화번호가 중복되면 안된다.
- 최소 선택 수량은 1개 이상.
- 전화번호는 01012341234 형태.
  
- 주문하기 페이지 고도화
